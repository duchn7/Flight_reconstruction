# Flight_reconstruction
Reconstruction of the takeoff and landing sequences of a commercial flight using public-domain and iPhone data.

Flight: KLM1078, Bristol (EGGD) to Amsterdam (EHAM), 9 November 2026
Aircraft: Embraer E190
Position data source: Flight Aware
Acceleration and Euler angle data source: iPhone 14 Pro Max, recorded using MATLAB for iOS
Runway data source: OpenStreetMap
Coding: Claude Sonnet 5.5
